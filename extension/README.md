# ThinkWrite Mirror Mode Extension

Build outputs:

- `dist/chrome` for Chrome and Edge
- `dist/firefox` for Firefox

Commands:

- `npm install`
- `npm run build`
- `npm run build:chrome`
- `npm run build:firefox`
- `npm run watch`

Load unpacked:

- Chrome/Edge: open extension settings and load `dist/chrome`
- Firefox: open `about:debugging` and load `dist/firefox/manifest.json`
